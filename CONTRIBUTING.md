# Contributing to the repo

You can report issues or suggest improvements through any of the following channels:

* **Pull Requests:** Open a pull request directly on this repository if you have something you want added, and our moderators will review it.
* **Discord Ticket:** Open a ticket in our [discord](https://discord.gg/kWmYexSVCt).
* **Direct Message:** Send a dm to [me](https://discord.com/users/1431639858174103563).
* **Email:** Contact me at [aurelium.support@gmail.com](mailto:aurelium.support@gmail.com).
